# Review and redesign verification

**Date:** 2026-11-12. **Scope:** fictional demo, not a production insurance service. The following statuses distinguish implemented work from external verification still required. No live Anthropic result, native Windows run or deployment is claimed.

## Interview UX pass

The home page now states the comparison purpose and fictional-data caveat up front. Form labels, hints, validation, focus and a keyboard-operable RTL select are consistent in both themes. Wider ranked cards show a sourced score contribution and a sourced non-coverage when available; neither is presented as the complete explanation of the rank. Section shortcuts and the mobile two-plan table make the flow easier to present. Rendering, ranking and model-selected facts treat values without evidence as unknown. See [the review and decisions](interview-ux-plan.md) and [the demo script](../DEMO.md).

The comparison no longer streams its interactive island inside a Suspense boundary: rapid history traversal during partial hydration could strand stale server-rendered controls. The home retains a skeleton; comparison entry links and the confirmation button announce pending navigation instead. Delayed-hydration and Back/Forward tests cover the trade-off.

## Decisions and manual follow-up

- **D-P1:** optional fictional annual premium, separately flagged against annual budget, excluded from coverage score; unknown never counts as a match. **D-P2:** rules, snapshot with model/date, and live-model labels remain distinct. **D-P3:** retain three active categories.
- **Real Anthropic:** set `ANTHROPIC_API_KEY` and `LLM_MODEL` privately, run `npm run snapshot` (12 catalogue documents), optionally `npm run snapshot -- --eval` (34 eval documents), then `npm run eval -- --snapshot`; inspect all results, seed the dedicated DB and rebuild. `npm run eval -- --live` additionally calls the model for extraction and intent. These calls can cost money.
- **Windows/clean install:** on native Windows with working Prisma CDN access, follow [setup-windows.md](setup-windows.md), run `npm ci`, migrations, seed and the full test/build list. The sandbox's `npm ci` postinstall could not reach the Prisma CDN; its engine cache workaround was local only and is not shipped.
- **Deploy/real proxy:** follow [deployment.md](deployment.md), then test normal same-origin search and rejection of a foreign origin via the actual HTTPS host. The sandbox could not reach its public HTTPS preview URL directly; the local server passed a forwarded-header simulation instead. `ALLOW_PREVIEW_EMBED=true` was used only for the Arena preview and must not be used for public production.
- **Human review:** test keyboard, screen readers, touch targets, contrast and real Persian policy interpretation with independent experts. Replace per-process abuse protection/cache for multi-instance production; PII detection and quote grounding are incomplete safeguards.
- **Agent workflow:** project roles and hooks were defined, but this environment supplied no independent subagent runner, Next DevTools MCP or Postgres MCP; local tests and manual review were used instead. All work remained on the session branch.
