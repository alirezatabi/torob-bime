# Initial implementation plan (historical)

The original demo established a schema-driven insurance catalogue, deterministic ranking, source-grounded coverage extraction, fictional fixtures, PostgreSQL persistence, Persian RTL pages and an evaluation suite. This plan is preserved as a short historical record; current work and remaining risks are tracked in [redesign-plan.md](redesign-plan.md).

The user subsequently chose npm and native Windows PostgreSQL rather than the original prompt's pnpm/Docker conventions. Model-dependent behavior remains optional; no real insurer prices or trust scores are implied.
